# Nguồn của bộ avatar mèo (CR-038)

`bad-cat.lottie` là clip "Bad Cat" do Creator cung cấp làm gốc; `tools/build_avatar.py` sinh các
biến thể `cat.*` từ file này (thêm viền, sọc mướp, biểu cảm, đạo cụ).

- Tác giả và giấy phép riêng của clip **chưa được xác minh**. File chỉ ghi "LottieFiles" (tên công
  cụ tạo file). Vì vậy mọi clip `cat.*` ở trạng thái `candidate` trong manifest.
- Trước khi duyệt: đọc giấy phép của chính clip trên trang nguồn, xác nhận có cho chỉnh sửa và
  phân phối lại, rồi điền `license_checked` và đổi `status` sang `approved`.
