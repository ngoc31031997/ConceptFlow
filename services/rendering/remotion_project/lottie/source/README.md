# Nguồn của bộ avatar mèo (CR-038)

`bad-cat.lottie` là clip "Bad Cat" do Creator cung cấp làm gốc; `tools/build_avatar.py` sinh các
biến thể `cat.*` từ file này (thêm viền, sọc mướp, biểu cảm, đạo cụ).

- **Giấy phép:** Creator xác nhận ngày 2026-09-26 trên trang clip gốc: "Free to use under the Lottie
  Simple License". Giấy phép này cho tải, chỉnh sửa, phân phối và dùng thương mại; không bắt buộc ghi công.
- Tác giả và URL trang nguồn chưa được ghi lại. File chỉ ghi "LottieFiles" (tên công cụ tạo file).
  Nên bổ sung vào `manifest.json` (`author`, `source_url`) khi có.
- Nếu đổi sang clip gốc khác, phải kiểm lại giấy phép riêng của clip đó và cập nhật `license_checked`.
